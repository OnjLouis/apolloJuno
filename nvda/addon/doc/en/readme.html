Apollo II for NVDA

Version 1.2. Requires NVDA 2026.2 or later on 64-bit Windows.

This add-on provides two UK English voice profiles based on the Dolphin Apollo II. The Juno profile's pronunciation, intonation and tone have been adjusted using recordings from a real Dolphin Juno. These profiles are approximations, not exact reproductions of every Apollo or Juno revision. No hardware, voice download or network connection is needed.

Getting started

  1. Install the add-on and restart NVDA.
  2. Open the synthesizer dialog with NVDA+Control+S.
  3. Choose Apollo II for NVDA.

The add-on uses NVDA's selected speech output device. Control stops speech; Shift pauses or resumes it. The previous synthesizer remains available in the synthesizer dialog.

Speech settings

Voice, rate, pitch, volume, intonation, bass and treble are available in NVDA's Speech settings and the synthesizer settings ring. Save NVDA's configuration to retain changes.

Louder passages automatically use less gain when needed to avoid clipping; this does not change your saved volume setting.

Bass and treble changes apply to subsequent speech. Strong boosts may reduce the overall level to leave safe headroom. Set both to 50 to restore the calibrated sound. NVDA's capital-letter pitch change is supported; the engine's sixteen pitch steps still mean some adjacent slider values sound identical.

Comparing the voices

Juno (calibrated) keeps the sound of version 1.0, including the pronunciation corrections, measured intonation contours and tonal adjustments. It remains selected when upgrading an existing installation.

Apollo II (original) uses the upstream Apollo II Reborn pronunciations, prosody, pitch mapping and tone before the Juno adjustments. It refers to the upstream reconstruction, not an exact recording or emulation of the original hardware DSP.

Choose Voice in Speech settings or the synthesizer settings ring. Both profiles use the same controls, audio device, spelling, Say All and pause support. Set bass and treble to 50 for a comparison without extra EQ. Turn off Read numbers as words to compare the original digit pronunciations: when enabled, it changes 1 to the word one before either voice receives it. NVDA's dictionaries can also change text before synthesis. Volume and clipping protection still apply to both, so this is a comparison of voice character rather than original hardware output level. Save NVDA's configuration to retain the selected voice.

On upgrading from version 1.0, an existing NVDA voice dictionary is copied to Juno (calibrated), leaving the old file intact. An existing dictionary for the new voice name is never overwritten. Apollo II (original) has its own voice dictionary; NVDA's default dictionary continues to apply to both profiles.

Reading numbers

Enable Read numbers as words in Speech settings to expand ordinary integers, decimals and ordinals before speaking. For example, 123 becomes one hundred and twenty-three, 3.05 becomes three point zero five, and 21st becomes twenty-first. The option is off by default, preserving hardware-style reading.

Leading-zero codes, phone-like groups, IP addresses, version strings, dates, email addresses and web links are left unchanged. Valid 24-hour times are read as times: 16:30:29 becomes sixteen thirty and twenty-nine seconds; 09:05 becomes nine oh five. Invalid times are left unchanged. Ambiguous or unusually long numbers are also left alone. This is not a date, currency or telephone interpretation service. Save NVDA's configuration to retain your choice.

With Juno (calibrated), intonation at faster rates is reduced in smaller steps, following the Juno's behaviour rather than the older Apollo firmware's abrupt limits. The highest rate is nearly flat. This does not change your selected intonation value; lowering the rate restores its effect. Apollo II (original) retains the older firmware's more abrupt high-rate limits.

Inline commands

Enable Allow inline commands in NVDA's Speech settings to interpret commands inside double braces. This checkbox is off by default and is not in the synthesizer ring. Enable it only when you want marked text to control the voice or play effects. Marked text from documents or websites can then do so.

Use one command per marker. Commands are case-insensitive; spaces just inside the braces are optional. Ordinary unwrapped commands are not executed. Unsupported, invalid, nested or incomplete markers remain ordinary text, subject to NVDA's normal punctuation settings. Spelling reads characters rather than executing markers.

Normal speech. {{@W5}}{{@R7}}Faster and more expressive!
{{@F4}}Lower pitch. {{@A6}}Quieter speech.
{{@T8}}{{reset}}Back to my configured controls.

Changes apply within one supplied speech sequence, including its internal text chunks and playback indexes. They do not change saved voice settings. {{reset}} restores your configured controls immediately for the next text. New speech sequences and cancellation start cleanly. During Say All, NVDA can supply separate paragraphs or lines as separate sequences; repeat markers where needed rather than expecting them to stay active for the entire document.

SoundWave's normal text capture can use the same markers. Enable this option and save NVDA's configuration before opening SoundWave's voice dialog, so its separate driver instance loads the choice. You do not need a special SoundWave plug-in. Text supplied as one render keeps its command changes until reset or the end of that input. Normal NVDA speech does not inherit changes from a render.

{{@T0}} to {{@TF}}0 to 9, A to FPlay one effect. 0 to 3 are whooshes, 4 to 7 buzzers, 8 to B the first warble, and C to F the second warble. Each group runs shortest to longest.
{{@TX}}XA short silent effect. This implementation produces approximately 210 milliseconds including its boundary silence; it is not an exact timing control.

Hexadecimal uses 0 to 9 followed by A, B, C, D, E and F for values ten through fifteen. Each command marker can introduce an audio boundary, which can affect phrasing. The preset voices are approximations: hardware source-wave and mark-space controls are not reproduced by this renderer.

Hardware reset, serial setup, language-bank changes, queries, echo commands, phonetic mode, mark-space ratio and source-wave commands are not supported here. The voice-off command @V0 is also excluded; use {{@A0}} for silent passages and {{reset}} to restore your settings. Native pitch is stepped, not a calibrated musical-note interface, so singing and exact musical timing are not guaranteed.

Updates

Open Apollo II for NVDA in NVDA Settings. Choose Never, Hourly or Daily for automatic update checks; Daily is the default. Check now checks immediately, including when automatic checks are disabled. Save NVDA's configuration to retain your choice.

Checks contact the add-on's GitHub repository and do not send speech text. You choose whether to install an available update. Downloads must have a valid publisher signature and match the expected add-on, version, size and hash. NVDA stages the update and asks you to restart; voice settings are retained.

Limitations

  • Both profiles are UK English. This build does not provide other languages.
  • Very long text is divided into bounded sections, which may affect phrasing.
  • Pronunciation and tone can differ from particular Apollo or Juno hardware versions.
